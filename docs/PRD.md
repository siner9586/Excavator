# PRD

## 产品定位

重机严选是面向个人机主、施工队、设备商、租赁公司、工程承包商的二手挖掘机可信交易平台。平台解决真实车源、权属清晰、验机可信、价格透明和交付可控五个核心痛点。

## 用户角色

- 买家：找车、询价、求购、预约验机、物流金融需求。
- 卖家：发布车源、接受验机、进入担保交易流程。
- 商家：发布批量车源、申请入驻、提供服务能力。
- 验机师：执行验机订单，生成报告。
- 运营：审核车源、跟进线索、处理风控。
- 管理员：配置规则、查看审计和运营指标。

## MVP 范围

- 车源发布与审核
- 车源搜索筛选与详情展示
- 询价、求购、验机预约、物流金融线索
- 商家入驻申请
- 估价规则模型
- 风控规则模型
- 后台运营看板和审核中心

## 非 MVP 范围

真实支付扣款、真实放贷、真实电子签章、对象存储上传、完整登录权限、拍卖、出口履约。
