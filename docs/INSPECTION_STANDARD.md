# Inspection Standard

## 五级体系

- A 级：车况优秀，无重大维修，核心系统正常。
- B 级：正常使用痕迹，少量维修，不影响施工。
- C 级：明显磨损，需要保养或小修。
- D 级：存在较大维修记录，适合低价工地使用。
- E 级：事故机、重大故障机、拆件或维修后使用。

## 十大项目

1. 发动机启动、烟色、漏油和异响
2. 液压泵压力、动作协调和油温
3. 大小臂、铲斗、销轴和结构件裂纹
4. 底盘四轮一带磨损
5. 电路系统、仪表和传感器
6. 回转系统间隙和制动
7. 驾驶室、空调和安全件
8. 出厂铭牌、发动机号和车架号
9. 权属资料、发票和抵押风险
10. 试机动作、复合动作和施工负载

## 服务边界

验机报告用于交易辅助，不等同于质量担保，不替代合同条款，不承诺未来故障零发生。
