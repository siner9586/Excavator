# Roadmap

## P0 MVP

- Next.js + Prisma + Neon + Vercel 基础架构
- 前台交易页面和后台管理页面
- Seed 数据和基础文档
- Vercel 部署和 GitHub Actions

## P1 商业化

- Auth.js + RBAC
- 商家会员和车源置顶
- 验机订单派单和报告 PDF
- 线索 CRM 和运营跟进状态

## P2 交易闭环

- 担保支付接口
- 电子合同接口
- 物流合作方报价
- 交易争议处理

## P3 数据智能

- 真实成交价数据集
- 估价模型迭代
- 风控评分配置化
- 搜索引擎和推荐模型
